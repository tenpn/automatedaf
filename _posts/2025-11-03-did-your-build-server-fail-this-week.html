Did your build server fail this week?

...is that a good thing, or a bad thing?

A week were your build server was 100% green is a week where either it failed to catch some bugs or no-one did any work.

Remember, the build server is there to help us, build failures are useful and desirable.

Look over the changes in your game from the past week: of the bugs you found, can any be turned into simple effective automated tests?

Were you bitten by a workflow or editor problem that could be turned into an asset test (alongside improving your tools!)?

When QA played the build, were they able to be productive, or did they quickly find blockers?

Try prioritising work that helps your build server go red for a few weeks, and see what kind of improvements it makes to the team's productivity.
