This week, I've got a link dump for you:

For Unreal users, check out this talk from Matt Oztalay about the work-in-progress Automated Performance Testing plugin. This looks like it does a lot of heavy lifting for you. https://www.youtube.com/watch?v=IamXWkYibZk

If you use Unity Test Framework, you might find this package useful, which adds a bunch of helper functions and attributes. The Is.Destroyed constraint alone is worth the price of admission! https://github.com/nowsprinting/test-helper

This video from AI and Games is exciting, about Ubisoft using ML to simulate console performance on PC, to both monitor game-wide performance cheaply, and shorten the feedback loop for people working on new art and systems: https://www.youtube.com/watch?v=3WvHdKY1ZB0

I did a talk for Ministry Of Testing, an org focused on the wider tech industry, about my approach to automation in video games. It's here but requires a paid membership: https://www.ministryoftesting.com/talks/bang-for-buck-automa...

And lastly, Automated AF has been helping a ton of projects over the last year, and one has finally shipped. You can pick up Cleared Hot on Steam in Early Access, where it's already doing great numbers: https://store.steampowered.com/app/1710820/Cleared_Hot/

Happy testing!
